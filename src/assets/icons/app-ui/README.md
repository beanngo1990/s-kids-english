# App UI Icons

Bundled PNG icons for app chrome and parent-facing controls.

- Source: `scripts/generateAppUiIcons.mjs`.
- Output: 128x128 transparent PNG files.
- Runtime: local `require(...)` through `src/assets/icons/app-ui/index.ts`.
- Scope: UI chrome only; these files are not part of the lesson image pipeline, asset manifest or R2 upload workflow.
